# Expected time for specific number of events

Expected time for specific number of events

## Usage

``` r
expected_t_at_d(d = 20, fail_rate, enroll_rate, interval = c(0.001, 1e+06))
```

## Arguments

- d:

  Events of interest

- fail_rate:

  Failure rate information

- enroll_rate:

  Enrollment information

- interval:

  Interval for root finding

## Value

Expected time
