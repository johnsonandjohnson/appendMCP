# Plot average hazard ratio over time by hypothesis

Plot average hazard ratio over time by hypothesis

## Usage

``` r
plot_distribution_tte_ahr(hypotheses, enroll_rate, time_grid = seq(0, 60, 0.5))
```

## Arguments

- hypotheses:

  Hypotheses object from processed config

- enroll_rate:

  Enrollment rate data frame

- time_grid:

  Time sequence for plotting

## Value

ggplot object
