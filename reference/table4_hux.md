Table 4: Summary of alpha allocation by hypothesis

## Usage

``` r
table4_hux(table4, pval_digits = 5, font_size = NULL)
```

## Arguments

- table4:

  data.frame version of table4

- pval_digits:

  Number of decimal places for local alpha level

- font_size:

  Font size in points, or NULL to use document default

## Value

huxtable version of table4
