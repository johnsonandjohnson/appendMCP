# Table 1: Trial Design Summary

Table 1: Trial Design Summary

## Usage

``` r
table1_hux(table1, n_digits = 0, font_size = NULL)
```

## Arguments

- table1:

  data.frame version of table1

- n_digits:

  Number of decimal places for maximum events / sample size

- font_size:

  Font size in points, or NULL to use document default

## Value

huxtable version of table1
