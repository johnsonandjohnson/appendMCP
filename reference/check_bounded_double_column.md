# Check bounded double column

Check bounded double column

## Usage

``` r
check_bounded_double_column(
  df,
  col_name,
  lower_bound,
  upper_bound,
  strict = FALSE
)
```

## Arguments

- df:

  Data.frame

- col_name:

  Column name

- lower_bound:

  Lower bound

- upper_bound:

  Upper bound

- strict:

  If TRUE, bounds are exclusive
