# Check sf and sfpar combination

Check sf and sfpar combination

## Usage

``` r
check_sf_sfpar(sf, sfpar, n_analyses, alpha, row_num)
```

## Arguments

- sf:

  Spending function

- sfpar:

  Spending function parameter

- n_analyses:

  Number of analyses

- alpha:

  Alpha level

- row_num:

  Row number for error messages
