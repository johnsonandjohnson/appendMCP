# Create summary tables

Create summary tables

## Usage

``` r
create_summary_tables(
  analyses,
  hypotheses,
  graph,
  weights,
  sim_results = NULL,
  alpha = 0.025
)
```

## Arguments

- analyses:

  Processed analyses

- hypotheses:

  Processed hypotheses

- graph:

  Graph object

- weights:

  Weight scenarios

- sim_results:

  Simulation results (optional)

- alpha:

  Overall Type I error rate

## Value

List of summary tables
