# Plot information factor or fraction over time for each hypothesis

Plot information factor or fraction over time for each hypothesis

## Usage

``` r
plot_information(config, time_grid = seq(0, 50, 1), use_fraction = FALSE)
```

## Arguments

- config:

  Configuration list

- time_grid:

  Time sequence for plotting

- use_fraction:

  Logical, if TRUE plot information fraction, if FALSE plot information
  factor

## Value

ggplot object
