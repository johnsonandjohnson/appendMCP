# Get long description of analysis trigger

Get long description of analysis trigger

## Usage

``` r
get_description_trigger_long(
  endpoint,
  strata,
  treatments,
  sample_size,
  events,
  description_short,
  distribution
)
```

## Arguments

- endpoint:

  Endpoint name

- strata:

  Strata

- treatments:

  Treatments

- sample_size:

  Sample size

- events:

  Number of events

- description_short:

  Short description

- distribution:

  Distribution object

## Value

Long description string
