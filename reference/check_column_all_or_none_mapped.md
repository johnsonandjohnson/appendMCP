# Check that mapped columns are present in all objects or none

Check that mapped columns are present in all objects or none

## Usage

``` r
check_column_all_or_none_mapped(objects, col_map, col_desc)
```

## Arguments

- objects:

  Named list of data.frames

- col_map:

  Named list mapping object names to column names

- col_desc:

  Description for error message
