# Table 3: Summary by criteria for conduct

Table 3: Summary by criteria for conduct

## Usage

``` r
table3_hux(
  table3,
  n_digits = 0,
  time_digits = 1,
  info_fraction_digits = 1,
  font_size = NULL
)
```

## Arguments

- table3:

  data.frame version of table3

- n_digits:

  Number of decimal places for events / sample size

- time_digits:

  Number of decimal places for expected analysis time

- info_fraction_digits:

  Number of decimal places for information fraction

- font_size:

  Font size in points, or NULL to use document default

## Value

huxtable version of table3
