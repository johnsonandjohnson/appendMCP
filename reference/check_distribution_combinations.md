# Check distribution combinations exist

Check distribution combinations exist

## Usage

``` r
check_distribution_combinations(
  endpoint,
  strata,
  treatments,
  dist_tte,
  dist_bin,
  field_name,
  row_num
)
```

## Arguments

- endpoint:

  Endpoint name

- strata:

  Strata vector

- treatments:

  Treatments vector

- dist_tte:

  TTE distribution data.frame

- dist_bin:

  Binary distribution data.frame

- field_name:

  Field name for error messages

- row_num:

  Row number for error messages
