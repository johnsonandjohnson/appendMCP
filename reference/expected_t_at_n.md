# Expected time for specific sample size

Expected time for specific sample size

## Usage

``` r
expected_t_at_n(
  n = 100,
  maturity_time = 6,
  enroll_rate = gsDesign2::define_enroll_rate(duration = 10, rate = 10)
)
```

## Arguments

- n:

  Sample size of interest

- maturity_time:

  Endpoint maturity time

- enroll_rate:

  Enrollment information

## Value

Expected time
