# Expected sample size at specific time

Expected sample size at specific time

## Usage

``` r
expected_n_at_t(
  t = 10,
  maturity_time = 6,
  enroll_rate = gsDesign2::define_enroll_rate(duration = 10, rate = 10)
)
```

## Arguments

- t:

  Time point of interest

- maturity_time:

  Endpoint maturity time

- enroll_rate:

  Enrollment information

## Value

Expected sample size
