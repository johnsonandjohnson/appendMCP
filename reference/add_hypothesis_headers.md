# Function to add hypothesis header rows (removes hypothesis column)

Function to add hypothesis header rows (removes hypothesis column)

## Usage

``` r
add_hypothesis_headers(hux_table, data, n_cols)
```

## Arguments

- hux_table:

  A hux table to modify

- data:

  the original data.frame version of the above table

- n_cols:

  Number of columns

## Value

Modified hux table
